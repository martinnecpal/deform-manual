# 26.6.10. **Nastavenie modelu CA**

Modely bunkových automatov (CA) sú synchronné algoritmy, ktoré opisujú diskrétny priestorový a časový vývoj zložitých systémov prostredníctvom uplatňovania lokálnych (alebo mezoskopických, stredného dosahu) deterministických alebo pravdepodobnostných transformačných pravidiel na bunky mriežky s lokálnou konektivitou. Ďalšie informácie nájdete v [Material Suite Labs for Cellular Automata (CA) model](/docs/en/labs/material_suite_labs/material_suite_labs_for_ca_model/).
