# 16.10. Používateľ (USRSUB)

[2D, 3D]: Toto číslo používateľskej rutiny (USRSUB) rozhoduje o tom, ktorá používateľská rutina sa použije na aktualizáciu používateľských premenných. Rozsah tohto čísla používateľskej rutiny je 1-100 (pozri obr. 16.10.1.). Ďalšie informácie o používateľskej rutine nájdete v časti [56\. User routine Chapter](/docs/sk/User_Routines/56_User_Routines_in_DEFORM/56_User_Routines_in_DEFORM/)[.](/docs/sk/User_Routines/56_User_Routines_in_DEFORM/56_User_Routines_in_DEFORM/)
