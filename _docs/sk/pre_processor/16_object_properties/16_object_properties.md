# 16\. Vlastnosti objektu

Rôzne parametre objektu, ktoré ovplyvňujú buď tepelno-mechanické správanie objektu, alebo správanie numerického riešenia, sa zadávajú v okne Object-Properties (Vlastnosti objektu). (Pozri obr. 16.1. a obr. 16.2.)

![]({{ '/assets/images/pre-processor/16_object_properties/16_image001.jpg' | relative_url }})

Okno Vlastnosti 2D objektu

![]({{ '/assets/images/pre-processor/16_object_properties/16_image002.jpg' | relative_url }})

Okno Vlastnosti 3D objektu

Možnosti Vlastnosti objektu sú rozdelené do týchto kategórií:

  * [Thermal]({{ '/docs/sk/pre_processor/16_object_properties/16_2_thermal_properties/' | relative_url }})
  * [Reference]({{ '/docs/sk/pre_processor/16_object_properties/16_3_Reference/' | relative_url }})
  * [Fracture]({{ '/docs/sk/pre_processor/16_object_properties/16_4_Fracture_properties/' | relative_url }})
  * [Hardness]({{ '/docs/sk/pre_processor/16_object_properties/16_5_hardness_properties/' | relative_url }})
  * [Heating]({{ '/docs/sk/pre_processor/16_object_properties/16_6_heating_properties/' | relative_url }})
  * [Symmetry]({{ '/docs/sk/pre_processor/16_object_properties/16_7_symmetry_properties/' | relative_url }})
  * [Body Force]({{ '/docs/sk/pre_processor/16_object_properties/16_8_body_force/' | relative_url }})
  * [RSE]({{ '/docs/sk/pre_processor/16_object_properties/16_9_rse/' | relative_url }})
