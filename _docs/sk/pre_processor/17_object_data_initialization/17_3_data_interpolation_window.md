# 17.3. Okno interpolácie údajov ![]({{ '/assets/icons/pre_icons/mo_data_interpolation_icon.jpg' | relative_url }})

**[2D, 3D]** : Pomocou možnosti Interpolácia údajov môže používateľ interpolovať údaje o objekte z iného objektu pomocou inej databázy. (Pozri obr. 17.3.1.)

Po výbere databázy môže používateľ vybrať číslo kroku (pozri obr. 17.3.2.) a vybrať objekt, z ktorého sa majú údaje interpolovať (pozri obr. 17.3.3.). Potom kliknite na ![]({{ '/assets/icons/pre_icons/mo_interpolate_button2.jpg' | relative_url }}), aby ste interpolovali údaje. Ak chce používateľ interpolovať údaje okrajových podmienok, potom začiarknite políčko "Interpolate boundary conditions" (Interpolovať okrajové podmienky).
