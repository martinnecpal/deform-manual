# 16\. Object Properties

Miscellaneous object parameters, which affect either thermo-mechanical behavior of the object or numerical solution behavior, are specified in the Object-Properties window. (See Fig. 16.1. and Fig. 16.2.)

![]({{ '/assets/images/pre-processor/16_object_properties/16_image001.jpg' | relative_url }})

2D Object Properties window

![]({{ '/assets/images/pre-processor/16_object_properties/16_image002.jpg' | relative_url }})

3D Object Properties window

Object Properties options are categorized as: 

  * [Deformation]({{ '/docs/en/pre_processor/16_object_properties/16_1_deformation_properties/' | relative_url }})
  * [Thermal]({{ '/docs/en/pre_processor/16_object_properties/16_2_thermal_properties/' | relative_url }})
  * [Reference]({{ '/docs/en/pre_processor/16_object_properties/16_3_Reference/' | relative_url }})
  * [Fracture]({{ '/docs/en/pre_processor/16_object_properties/16_4_Fracture_properties/' | relative_url }})
  * [Hardness]({{ '/docs/en/pre_processor/16_object_properties/16_5_hardness_properties/' | relative_url }})
  * [Heating]({{ '/docs/en/pre_processor/16_object_properties/16_6_heating_properties/' | relative_url }})
  * [Symmetry]({{ '/docs/en/pre_processor/16_object_properties/16_7_symmetry_properties/' | relative_url }})
  * [Body Force]({{ '/docs/en/pre_processor/16_object_properties/16_8_body_force/' | relative_url }})
  * [RSE]({{ '/docs/en/pre_processor/16_object_properties/16_9_rse/' | relative_url }})
  * [User]({{ '/docs/en/pre_processor/16_object_properties/16_10_user/' | relative_url }})
